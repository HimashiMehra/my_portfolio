Development Report

1. Reflection (250+ Words)

Building this portfolio website has been a significantly rewarding experience that solidified my understanding of modern web development principles. The primary goal was to create a professional, responsive, and visually striking personal portfolio using purely core web technologies—HTML5, CSS3, and Vanilla JavaScript—without relying on external frameworks like Bootstrap or React. This constraint was incredibly beneficial as it forced me to deeply engage with modern CSS layout modules like CSS Grid and Flexbox, which are essential for crafting complex, responsive designs that adapt seamlessly across devices.

Throughout the development process, I learned the importance of planning a robust CSS architecture. By utilizing CSS custom properties (variables) for colors, spacing, and typography, I was able to maintain consistency across all five pages and create a cohesive dark and light color combination theme. Implementing the mobile-first approach ensured that the core structure was sound before adding complex desktop layouts. I particularly enjoyed creating the responsive navigation bar with a custom hamburger menu using JavaScript, which enhanced the user experience on mobile devices.

The project also taught me valuable lessons about accessibility and semantic HTML. By using tags like <header>, <nav>, <main>, and <section>, I ensured the code is readable by both developers and assistive technologies. Overall, this assignment has boosted my confidence in my ability to take a design concept and translate it into clean, maintainable, and interactive web code from scratch.

2. Learning Experience

My key learning outcomes included mastering CSS Grid for the project cards layout, understanding how to implement custom form validation using JavaScript before submitting via mailto:, and properly embedding third-party content like Google Maps and YouTube videos ensuring they remain responsive.

3. Development Process

The development followed a systematic approach:

  • Planning: Outlining the folder structure and identifying required assets.

  • HTML Skeleton: Building semantic markup for all five pages.

  • Styling (CSS): Establishing the design system (variables, fonts) in style.css and applying it to layouts.

  • Interactivity (JS): Adding the mobile navigation toggle and form validation in script.js.

  • Testing: Verifying responsiveness across different viewports.

4. Design Decisions

I opted for a modern, dark-themed aesthetic with vibrant electric blue and purple accents to give it a premium, tech-focused feel. The typography pairs 'Outfit' for bold, modern headings and 'Inter' for highly readable body text. Glassmorphism effects (subtle transparency and blur) were used on the navigation and cards to add depth.

5. Problems Faced and Debugging

A significant challenge was making the CSS Grid on the projects page responsive without using media queries for every breakpoint. I solved this by utilizing the repeat(auto-fill, minmax(350px, 1fr)) function in CSS Grid, which automatically handles the wrapping of cards. Additionally, aligning the custom form validation error messages required careful DOM manipulation in JavaScript.

6. Font and Colour Selection

  • Fonts: Google Fonts: 'Outfit' (Headings) and 'Inter' (Body).

  • Colours: Backgrounds (Deep Blue #0f172a, #1e293b), Text (Light #f8fafc, #cbd5e1), Accents (Blue #3b82f6, Purple #8b5cf6).

7. Inspiration Websites

The design was inspired by modern tech portfolios and platforms like Dribbble, Awwwards, and the clean UI of Vercel and Stripe, focusing on dark modes and vibrant gradients.
